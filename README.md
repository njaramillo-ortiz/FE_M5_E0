## Preguntas teóricas sobre TypeScript

### ¿Qué es TypeScript y para qué se utiliza?
Es un lenguaje de programación que extiende las funcionalidades de JavaScript. Su principal utilidad es permitir el uso de tipado estático, lo cual da mayor estructura y claridad al código, además de reducir las posibilidades de errores.


### ¿Cuáles son las principales diferencias entre TypeScript y JavaScript?

TypeScript tiene tipado estático y JavaScript no. Además, TypeScript es un lenguaje compilado y JavaScript no.


### ¿Por qué es útil TypeScript en el desarrollo de aplicaciones ReactJS?

Porque nos permite dar mayor estructura y claridad al código, además de reducir las posibilidades de errores. Esto favorece la colaboración en proyectos de mayor tamaño.


### ¿Qué es el sistema de tipos en TypeScript y cómo ayuda a evitar errores en tiempo de desarrollo?

El sistema de tipado estático permite definir previamente el tipo de una variable, lo cual impedirá que se le asignen valores de otro tipo. Esto nos permite detectar posibles errores de manera temprana al compilar, y no en tiempo de ejecución.

## Ventajas de TypeScript en el Desarrollo con ReactJS

Mediante la resolución del ejercicio práctico se pudo comprobar las ventajas que tiene TypeScript a la hora de trabajar en desarrollo web. Principalmente, destacaría que es una ventaja enorme para la iteración poder detectar errores en tiempo de escritura y compilación en lugar de en tiempo de ejecución. 

También es útil poder conocer las diferentes mejoras sintácticas y estructurales que existen cuando uno trabaja con sistemas como Intellisense, que te permiten observar estas discordancias y conocer nuevas estructuras para optimizar tu código.

Finalmente, el resultado es una codebase más legible y fácil tanto de entender como de trabajar.
